# 📝 Enhanced To-Do List (with Local Storage)

A simple and enhanced To-Do List web app built with vanilla JavaScript, HTML, and CSS. Tasks are stored in the browser using `localStorage`, so they persist even after the page is reloaded.

## 🚀 Features

- ✅ Add new tasks with optional due dates
- ✅ Mark tasks as completed
- ❌ Delete tasks
- 🔍 Filter tasks by status: All, Active, Completed
- 🔀 Sort tasks by creation time or alphabetically
- 💾 Auto-save to local storage (no backend required)
